# A&B DigiNova — GitHub Pages Upload Package

## Before publishing: set WhatsApp
Open `site-config.js` and replace `923XXXXXXXXX` with your WhatsApp number in international format, digits only.
Pakistan example: `923001234567` (no +, spaces or dashes).
The Contact buttons open WhatsApp with a pre-filled greeting. The visitor presses Send in WhatsApp. No email is used.

## Upload
1. Download and extract this ZIP.
2. Open your existing public repository `ab-diginova`.
3. Upload the contents of the `AB_DigiNova` folder into the repository root.
4. Keep `assets/images` and `assets/audio` folders intact.
5. Replace old `index.html`, `style.css`, `script.js`, `README.md`; upload `site-config.js` too.
6. Commit changes. Keep GitHub Pages set to Deploy from a branch → `main` → `/(root)`.

## Included
- Portal entry with a short 2–3 second transition
- Soft muted neon theme
- Responsive Home, Academy, Competitions, Store, Blogs, About and Contact sections
- Academy subject placeholders and a dedicated competitions area
- Store ready for Shopify product links to be added later
- Blogs ready for articles to be added later
- Optional original synthesized sound effects (off by default)
- WhatsApp contact buttons (requires your number in site-config.js)

## Add later
Course details, fees, enrolment, competition dates/rules/results, blog articles and Shopify product links.

## Limitations
This is a static GitHub Pages website. It does not include a database, member login, student progress tracking, secure checkout or admin dashboard. Shopify should handle product payments and checkout; link products here when ready. Sound is off by default and requires the visitor to enable it.
